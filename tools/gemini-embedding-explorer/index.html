Gemini Embedding Explorer

Explore gemini-embedding-2, Google's multimodal embedding model. It has no task_type parameter — you steer embeddings by writing a task instruction directly into the prompt (e.g. task: search result | query: …). Add queries and markdown documents, experiment with instructions, and compare cosine similarities.
